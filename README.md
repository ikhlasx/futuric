# Futuric Website

A complete React + Vite single-page corporate website for Futuric, with NEXA presented as the flagship industrial venture.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy directly to Vercel. The included `vercel.json` handles SPA routing.

## Content source

The structure and wording are based on the provided Futuric website context and NEXA by Futuric brochure. Replace the text-only monogram/abstract visuals with approved brand assets when available.
